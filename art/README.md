# art

妖怪1体ごとの絵を置くフォルダです。

- 縦長（9:16）、文字・ロゴ・枠なし
- 形式は PNG か JPG
- ファイル名は妖怪名のローマ字、小文字

表の並びが、はじめて取り上げる順番です。ひととおり出たあとは、しばらく出ていない妖怪から順に繰り返します。

## 追加の絵（あると動画がよくなります）

同じ妖怪で、ファイル名の後ろに印をつけて置きます。なくても動画は作れます。

| ファイル名 | 中身 |
| --- | --- |
| `<名前>_title.png` | 妖怪の名前の筆文字。真っ黒の背景に白〜生成りの文字だけ。横長（3:1） |
| `<名前>_2.png` | 同じ妖怪の別の構図（顔のアップなど）。縦長 9:16、文字なし |
| `<名前>_3.png` | さらに別の構図（遠景・里の景色など）。縦長 9:16、文字なし |
| `<名前>_emaki.png` | 絵巻風の絵。横長 16:9、生成りの和紙に墨と淡い色、文字なし |

例: `bakegitsune_title.png` `bakegitsune_2.png` `bakegitsune_3.png`
